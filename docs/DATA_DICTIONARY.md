## Derived outputs (`analysis/output/`, regenerated by `run_audit.py`)

### Profiling
- **`source_record_counts.csv`** (13) — `source`, `records`.
- **`source_profile.csv`** (84) — per column: `rows`, `null_count`,
  `null_rate_pct`, `unique_non_null`, `is_candidate_join_key`,
  `whitespace_defects`, `casing_defects`, `malformed_values`,
  `malformed_names`, `min_date`/`max_date`, `duplicate_full_rows`,
  `duplicate_ids`.

### Entity resolution
- **`account_resolution.csv`** (142) — one row per account mention:
  `match_tier`, `canonical_account_id`, `domain_group`, `match_method`,
  `match_evidence`, `competing_candidates`.
- **`account_crm_groups.csv`** (50) — CRM records with `domain_group`,
  `domain_group_size`, `duplicate_class`, `resolution` (why they are held apart).
- **`account_similar_pairs.csv`** (2) — look-alike pairs with `name_similarity`,
  `discriminators`, `verdict`.
- **`account_canonical.csv`** (72) — canonical accounts with `name_variants`,
  `sources`, `mentions`, `crm_link`.
- **`person_resolution.csv`** (126) / **`person_identities.csv`** (5,030) —
  tiers, evidence, `conflicting_affiliation`, `missing_profile_url`.

### Request spine
- **`request_reconstruction.csv`** (200) — one normalised record per request.
  Key derived fields:
  - `derived_state` — state from evidence (`declared_only:` prefix when the only
    evidence is the self-declared status).
  - `state_evidence_rank` — `1_outcome_event` > `2_explicit_slack_statement` >
    `3_declared_status_only` > `4_no_evidence`.
  - `state_evidence`, `state_confidence` (`high`/`medium`/`low`/`none`).
  - `has_terminal_evidence`, `owner_known`, `next_action_known`.
  - `last_observed_activity`, `days_since_activity`,
    `inactivity_bucket` (`<7d`, `7-13d`, `14-29d`, `30d+`, `unknown`),
    `potentially_stale` — **staleness is independent of state**.
  - Slack flags: `slack_volunteer_offer`, `slack_referral_suggestion`,
    `slack_bump`, `slack_duplicate_query`, `slack_explicit_state_statement`.
- **`request_funnel.csv`** (9) — every stage with `count`, `denominator`, `pct`.
- **`request_latency.csv`** (6) — `n_observed`, `denominator`, `coverage_pct`,
  `median_days`, `p90_days`, `max_days`, `note`.
- **`stalled_requests.csv`** (200) — staleness view with `staleness_class`.
- **`slack_reconciliation.csv`** (7) — spine ↔ Slack ↔ outcomes checks.
- **`slack_message_intents.csv`** (523) — per message `intent`, `is_ask_like`,
  `referred_person`.
- **`audit_reference_date.json`** — the derived "today" and how it was chosen.

### Paths and connectors
- **`candidate_paths.csv`** (625) — one row per candidate edge:
  `edge_type` (`export_direct_target_person`,
  `export_colleague_at_target_account`, `investor_portfolio`,
  `investor_portfolio_board_seat`, `investor_alumni_prior_employer`),
  `relationship_date`, `recency_days_at_request`,
  `availability` (`time_aware_available` | `snapshot_only_historical_unknown` |
  `post_dates_request`), `confidence`, `limitations`, `connector_reachable`.
- **`path_coverage.csv`** (200) — per request: `n_paths_time_aware`,
  `n_paths_snapshot`, connector lists, `used_connector_was_observable`,
  `alternatives_to_used_connector`.
- **`connector_load.csv`** (11) — recorded asks, capacity, `months_over_capacity`,
  response/intro rates with coverage.
- **`connector_month_load.csv`** (49) — `asks` vs `stated_monthly_capacity`,
  `over_capacity`.
- **`connector_path_supply.csv`** (26) — observable paths vs asks actually made.

### Findings
- **`duplicate_candidates.csv`** (286) — same-account pairs with `overlap_type`,
  `days_apart`, `within_window` (90 days), `severity`.
- **`reask_analysis.csv`** (42) — self-declared repeats with the prior ask's
  state, `prior_was_routed`, `prior_had_terminal_evidence`.
- **`status_contradictions.csv`** (217) — `check`, `detail`, `severity`.
- **`leadership_observability.csv`** (6) — answerable / unanswerable counts and
  pipeline value per leadership question, with the `evidence_rule` applied.
- **`cross_source_findings.csv`** (11) — `numerator`, `denominator`, `pct`, `detail`.
- **`summary_metrics.json`** — headline metrics; every rate is
  `{numerator, denominator, pct}`.
- **`problem_scores.csv`** (6) — the ranked problems and their score components.
